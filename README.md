# 📱 Contact Management App

A Flutter-based **Contact Management App** developed as a Local Database CRUD assignment. The application allows users to store, view, search, update, delete, and manage favorite contacts using a local SQLite database.

## ✨ Features

* ➕ Add new contacts
* 👥 View all saved contacts
* ✏️ Update contact information
* 🗑️ Delete contacts with confirmation
* 🔍 Search contacts by name
* ⭐ Mark contacts as favorite
* ⭐ View only favorite contacts
* 💾 Store contacts locally using SQLite
* 📱 Clean and user-friendly Flutter UI
* 🌙 Light/Dark theme support

## 📋 Contact Information

Each contact contains:

* **ID** – Automatically generated by the database
* **Name** – Required
* **Phone Number** – Required
* **Email** – Contact email
* **Address** – Contact address
* **Favorite** – Favorite status

## 🗄️ Local Database

The application uses **SQLite** through the Flutter sqflite package.

The database table contains:

contacts
├── id
├── name
├── phone
├── email
├── address
└── isFavorite


All contact information is stored locally on the user's device.

## 📌 Important

The application does **not** use an online server or external database. Contact information is stored locally on the device using SQLite.

If the application is uninstalled, the locally stored database and contacts will normally be removed as well.
